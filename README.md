## 📌 Project Overview

The **Online Examination System** is a web-based application designed to simplify and automate the examination process for students and administrators.

The system allows:

* 👨‍🎓 Students to attend exams online
* 🧑‍💼 Admins to manage questions and results
* 📊 Automatic evaluation and score generation
* 🔐 Secure login and examination environment

This project helps reduce manual work and provides a fast, reliable, and scalable examination platform.

## 🚀 Features

* 🔐 Student & Admin Login System
* 📝 Online MCQ-based Examinations
* 📊 Automatic Result Calculation
* ⏳ Timer-based Exam System

## ⚙️ Installation & Setup

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/your-username/Online-Examination-System.git
cd Online-Examination-System
```

### 2️⃣ Move Project to XAMPP htdocs Folder

```text
C:/xampp/htdocs/
```

### 3️⃣ Start XAMPP Services

Start:

* Apache
* MySQL

---

### 4️⃣ Import Database

1. Open phpMyAdmin
2. Create a new database
3. Import the provided `.sql` file

---

### 5️⃣ Run the Project

Open browser:

```text
http://localhost/Online-Examination-System
```

## 🧠 How It Works

1. User logs into the system.
2. Admin creates exams and uploads questions.
3. Students attend exams within the time limit.
4. System automatically evaluates answers.
5. Results are generated instantly.
